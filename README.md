# 플로우 큐 (한글 지원)

Google Flow(flow.google.com)에서 Veo·Nano Banana 프롬프트를 순서대로 자동 제출하는 Chrome 확장입니다.
한글 프롬프트가 깨지지 않도록 문장 전체를 한 번에 입력하고, 버튼은 화면 글자 대신 `aria-label`로 찾습니다.

## 설치
1. `chrome://extensions` 를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소의 `extension` 폴더를 선택합니다.
4. Flow 프로젝트 페이지를 열고 툴바의 확장 아이콘을 누르면 사이드패널이 열립니다.

## 사용법
1. Flow 입력창 아래의 설정 버튼(예: `Video · 720p · 8s`)에서 모델·비율·길이·개수를 먼저 맞춥니다.
2. 사이드패널에 프롬프트를 붙여넣거나 TXT/CSV 파일을 불러와 **큐에 추가**합니다.
   - CSV는 `prompt` 또는 `프롬프트` 열을, 없으면 첫 번째 열을 사용합니다.
   - 엑셀에서 저장한 EUC-KR CSV도 자동으로 인식합니다.
3. **시작**을 누르면 제출 간격마다 하나씩 제출합니다.

## 문제가 생기면
사이드패널의 **진단 정보 복사**를 누르고 결과를 붙여넣어 보내 주세요. 입력창·버튼을 찾았는지 확인할 수 있습니다.
